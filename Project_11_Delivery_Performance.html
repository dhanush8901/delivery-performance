Operations · Project 11

Delivery Performance Crisis

Problem

Delivery delays and complaints rise even though logistics capacity is adequate. Analyse orders, warehouses, routes, staffing, stock and delivery data to find root causes.

Algorithm flow

InputProcessDecisionOutput
Join orders, warehouse pick/pack logs, route/carrier data, staffing rosters, stock availability
Compute delay = actual − promised per order; tag stage where time was lost
Aggregate delay by warehouse, route, shift, carrier, stock status
Root-cause model: decision tree / SHAP on 'late' flag
Which factor explains most late orders?
Stock-outs → rebalance inventory | Understaffed shifts → roster | Bad routes → re-optimise
Simulate fix, estimate on-time % gain
Root-cause ranking + improvement plan

Pseudocode

orders['late'] = orders.delivered > orders.promised
features = [wh_backlog, staff_per_order, route_km, carrier, stockout_flag, peak_hour]
tree = DecisionTree(max_depth=4).fit(features, late)
cause_share = shap_summary(tree)                 # % of late orders explained
for cause in ranked(cause_share):
    plan.append(FIX[cause])
new_late = predict(apply_fix(orders, chosen_fixes)).mean()
